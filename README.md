# 남식쌤 사진 압축 — 배포

사진과 한글 문서(HWP/HWPX), PDF 안의 사진을 압축하는 Windows용 도구입니다.

[최신 버전 v2.5 다운로드](https://github.com/namsigi/PhotoCompressor-releases/releases/latest)

## v2.5
- PDF 압축: 화질 우선 / 균형 / 용량 우선
- 숫자 입력칸의 세로 가운데 정렬
- 원본 보존 및 출력 파일 이름 중복 방지

Windows와 .NET Framework 4.8이 필요합니다. PhotoCompressor.exe를 실행하거나 ZIP을 풀어 실행하세요.
PDF 압축률은 문서에 따라 다르며, 암호·전자서명·입력 양식이 있는 문서는 건너뜁니다.
지원 범위, 검증 결과, 기존 이미지 라이브러리의 보안 경고는 [릴리스 설명](https://github.com/namsigi/PhotoCompressor-releases/releases/tag/v2.5)에 기록했습니다.

이 저장소는 실행 파일 배포용이며 앱 소스 코드는 포함하지 않습니다.
